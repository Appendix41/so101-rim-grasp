# 实验与消融

主线是单卡 π0.5 后训练下的 SO-101 薄罐沿抓放：抓取和放置使用各自的任务适配器，学生到达的状态由专家纠偏，再与已验证的旧经验一起训练。当前配对评测中，抓取 DAgger 的提升集中在抬起后的持罐交接；放置 DAgger 则改善了固定持罐起点下的落点决策。

## 双 LoRA

冻结 π0.5 基座按任务阶段切换适配器。抓取 LoRA `af182185` 预测关节动作块；放置 LoRA `9549e9c8` 预测桌面像素目标，几何 IK 将其转成搬运与释放动作。目标是黑布，红布为干扰项，两块布的位置可交换。

| 模块 | 训练版本 | 训练数据 |
|---|---|---|
| 抓取 | `ddfcb593` → `af182185` | 学生到达状态上的 DAgger 纠偏与已验证成功回放 |
| 放置 | `d7148f68` → `9549e9c8` | 旧示范与学生新状态上的放置标注 |

## 抓取 DAgger

在 40 个新训练工况中采集学生状态，经专家演示和持续稳持核验后选出 17 个新纠偏窗口；与 5 个历史纠偏、116 个成功能力回放合并，形成 **138 个训练窗口**。未通过核验的专家分支不作为正确动作标签。

训练时冻结 π0.5 基座，仅更新 rank 8、alpha 16 的 LoRA；采用归一化动作回归损失，学习率 `1.5e-5`，训练 80 步，batch size 4。每个 batch 含 2 个纠偏窗口和 2 个能力回放窗口；683 个控制帧带有手臂动作标签，夹爪由策略控制。训练进程峰值显存分配为 10.76 GiB。

### 完整抓放配对评测

固定放置 LoRA `9549e9c8` 和几何 IK，每个抓取版本执行相同的 16 个工况：4 个场景种子、熟悉/平移两种几何、黑布左右两种布局。关闭世界模型、视觉脚本重抓和人工接管。

| 指标 | 父版 `ddfcb593` | DAgger `af182185` |
|---|---:|---:|
| 首次持续抬升 | 15/16 | 15/16 |
| 持罐至 IK 交接 | 3/16 | **9/16** |
| 有效放置目标 | 2/16 | 3/16 |
| 严格完整抓放 | 1/16 | **2/16** |

主要变化是抬起后更常将罐保持至放置交接；首次持续抬升率相同，完整抓放仍取决于持罐和落点两阶段。配对视频展示同一验证工况中的父版失持与 DAgger 版成功，不代替 16 工况汇总：[完整抓放配对](../media/replays/dagger-full-task-pair.gif) · [单回合成功](../media/replays/pick-place.gif) · [布边越界案例](../media/replays/pick-place-overhang.gif)。

## 放置 DAgger

初版放置 LoRA `d7148f68` 从黑布动作 LoRA `47b6b912` 初始化，以 19 对专家示范训练。更新版 `9549e9c8` 从初版继续，混合 19 对旧样本与 8 对学生新状态上的放置标注；rank 8、alpha 16，训练 192 步，更新 643,584 个参数，抓取 LoRA 保持不变。

在 8 个配对开发起点上，严格放置成功从 **4/8 提升到 7/8**。该对照固定持罐起点和几何 IK，比较落点决策；黑布位置会变化，但目标指令仍是黑布。[颜色选择回放](../media/replays/placement-color.gif)展示更新前后的落点。

## 辅助实验

轻量后果模型从仿真执行结果拟合，在推理时估计抓取分支或放置候选的结果，用于分支和落点选择。

| 实验 | 结果 | 条件 |
|---|---:|---|
| 侧抓 / 夹罐沿 | 持续抬升 **2/9 / 8/9** | 几何专家；3 个起点、罐高 60、90、120 mm |
| 闭爪后继续策略 / 视觉脚本重抓 | 持续抬升 **1/8 / 8/8** | 学习式选择器 8/8 次选择视觉脚本重抓 |
| 放置 LoRA / 加入放置后果模型 | **7/8 → 8/8**，两组开发评测均如此 | 固定几何 IK |
| 注入落点：后果模型 / 视觉边界规则 | **28/32 / 32/32** | 候选点压力测试 |
| 双后果模型完整链路：父版 / `af182185` | 严格成功 **13/16 / 15/16** | 两版每回合均触发视觉脚本重抓 |

临边落点选择见[回放](../media/replays/placement-margin.gif)。逐工况数据：[DAgger 抓取记录](../evidence/grasp-dagger.json)、[抓取完整任务配对](../evidence/grasp-placement-pairs.json)、[放置开发记录](../evidence/dev-a.json)、[RL-token 侧线记录](../evidence/rl-side-study.json)。

## 评测范围

- 所有抓放结果来自 Isaac Sim 的开发、诊断或验证工况。
- 单卡 NVIDIA RTX PRO 5000 Blackwell；抓取 LoRA 训练进程峰值显存分配 10.76 GiB。
- 仿真控制频率 15 Hz，物理频率 120 Hz；动作块长度 50 步。
- 罐体使用壁厚 2 mm 的刚体模型；布面是桌面上的彩色目标区域。
- 当前结果未包含真机抓放或封存测试集评测；实体相机状态见[真机记录](../real/README.md)。
- 仓库不含 π0.5 基座、分词器或微调 LoRA 权重；许可与获取范围见 [NOTICE](../NOTICE.md)。
