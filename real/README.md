# Sim-to-real | 真机记录

**状态：本任务尚未进行真机验收，未发布成功视频，实机成功率未测。** 已有实体 SO-101，固定 D435i RGB 和腕部 USB RGB 曾验证可并发采集；这不是夹起、放稳或当前标定可复用的证明。这里不提供会上电发动作的脚本。

| 阶段 | 开什么、看什么 | 可留作证据 |
|---|---|---|
| 1. 双相机只读 | 从臂不动。摆两块布、交换近远；在实拍上叠罐沿、黑布轮廓、学生点和世界模型点。检查俯视投影、手眼标定、图像顺序和尺度；先看失效例。 | 两个布局的原图与叠图；记录是否开了专家、是否复用仿真阈值。 |
| 2. 低速只测抓 | 记下实物材质、罐高、外径、质量和可测壁厚；核对从臂关节映射、夹爪开合方向、限速与随手可用的停机方式。在有人监护、手不在工作区时，先验证空载悬停，再观察低高度试提。 | 俯视和腕部连贯视频；分别记夹空、滑落、倾斜、压痕和人工接管。 |
| 3. 再测放置 | 同一罐，分别令黑布处于近、远侧；记录请求落点、实际落点、整底是否越界、松手后是否连续稳定至少 2 秒。看不清的指标写 `unknown`，不要用仿真真值补。 | 放置双视角视频；标明自主、人工介入或纯遥操。 |

实拍审核后，第一段短片放到 **`real/demo.mp4`**，再在首页加上实际视频链接、日期与试验数。目前没有占位视频或虚构回合。每次尝试可在 [trials.csv](trials.csv) 追加一行，包括失败和停止；首条录像可作为演示，不据此报泛化率。未剪辑原片和包含个人信息的标定留在被 Git 忽略的 `real/raw/`、`real/private/`。
