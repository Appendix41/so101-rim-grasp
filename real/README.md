# Sim-to-real | 真机记录

实体 SO-101 已就位，固定 D435i 俯视相机与腕部 USB RGB 相机已验证可并发采集。当前进度为相机画面和标定复核；本任务的真机抓放评测尚未开始，暂无公开实机视频或成功率。

## Sim-to-real 验证顺序

本页记录验证流程与数据字段。动作评测按视觉、抓取、放置逐阶段推进，并保留人工接管和失败记录。

| 阶段 | 开什么、看什么 | 可留作证据 |
|---|---|---|
| 1. 双相机只读 | 从臂不动。摆两块布、交换近远；在实拍上叠罐沿、黑布轮廓、学生点和世界模型点。检查俯视投影、手眼标定、图像顺序和尺度；先看失效例。 | 两个布局的原图与叠图；记录是否开了专家、是否复用仿真阈值。 |
| 2. 低速只测抓 | 记下实物材质、罐高、外径、质量和可测壁厚；核对从臂关节映射、夹爪开合方向、限速与随手可用的停机方式。在有人监护、手不在工作区时，先验证空载悬停，再观察低高度试提。 | 俯视和腕部连贯视频；分别记夹空、滑落、倾斜、压痕和人工接管。 |
| 3. 再测放置 | 同一罐，分别令黑布处于近、远侧；记录请求落点、实际落点、整底是否越界、松手后是否连续稳定至少 2 秒。无法从图像确认的指标记为 `unknown`。 | 放置双视角视频；标明自主、人工介入或纯遥操。 |

通过首轮实机审核后，将经核验的双视角片段放到 **`real/demo.mp4`**，并在首页记录日期和试验数。每次尝试都在 [trials.csv](trials.csv) 追加一行，包括失败、停止和人工接管；未剪辑原片及包含个人信息的标定保存在 Git 忽略的 `real/raw/`、`real/private/`。
